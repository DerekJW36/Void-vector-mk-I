Real-time 3D viewer for the VoidVector Mk I built with Three.js + Cannon-es.

## Geometry

| Property | Value |
|---|---|
| Frame | Regular Tetrahedron |
| Edge Length | 420 mm |
| Vertices / Thrusters | 4 (T1 Apex, T2 Base-Front, T3 Base-Left-Rear, T4 Base-Right-Rear) |
| Structural Edges | 6 carbon-fibre tubes |
| Airflow Channels | 4 triangular negative-space faces (CH-1…CH-4) |
| AUW | 2.8 kg |
| Max Combined Thrust | 74 N (2.69:1 TWR) |
